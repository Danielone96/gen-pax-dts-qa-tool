# Guida all'Installazione del Generatore Dati

Questa guida spiega come installare ed eseguire l'applicazione per la generazione di dati passeggeri.

## Prerequisiti

L'unico prerequisito è avere **Python 3** installato sul proprio computer.

L'applicazione utilizza la libreria `tkinter` per l'interfaccia grafica, che è inclusa nella maggior parte delle installazioni standard di Python.

## Installazione

Non è richiesta una vera e propria installazione. È sufficiente avere tutti i file del progetto nella stessa cartella:

- `gui_app.py`
- `home.py`

## Esecuzione

1. Apri un terminale o un prompt dei comandi.
2. Naviga fino alla cartella dove hai salvato i file del progetto.
3. Esegui il seguente comando:
   ```bash
   python gui_app.py
   ```
4. L'interfaccia grafica dell'applicazione si avvierà.
